# Maccap

专为 **Apple Silicon 苹果电脑（Mac / Studio Display 外接 PS5）** 打造：通过免驱 HDMI 采集卡直接读取 PS5 的 30 帧大作画面，用苹果显卡实时补到 60 帧全屏低延迟显示，并自动同步 PS5 声音。不走网络串流，不抓屏。

Real-time low-latency frame interpolation (30 → 60 fps) designed for Apple Silicon Macs connected to a PS5 via a UVC HDMI capture card (`macOS 14.0+`).

## 为什么做这个工具

很多苹果用户桌面只有一台 Mac 或一块 5K Studio Display（不支持直接插 HDMI 线），玩 PS5 的 30 帧画质模式大作时转动视角卡顿感明显。插一块免驱采集卡打开本软件，就能在 Mac 屏幕上用 60 帧流畅度与原生清晰度直接游玩。

## 系统与连接准备

1. **苹果电脑**：Apple Silicon（M1 / M2 / M3 / M4 / M5 全系芯片，不支持老款 Intel Mac），**macOS 14.0（Sonoma）或更新系统**。
2. **PS5 主机端必设 5 项**（只需设一次）：
   - **关闭 HDCP**（系统 → HDMI → 启用 HDCP：关，否则采集卡黑屏）
   - **关闭 HDR**（屏幕和视频 → 视频输出 → HDR：关）
   - **关闭 VRR** 与 **关闭 120Hz 输出**
   - **分辨率设为 2160p（4K）或 1080p，60Hz**（即使软件内限制 2K/1080p，PS5 端也可保持 4K 不用改）
   - **声音输出设为「2 声道线性 PCM（Linear PCM）」**
3. **免驱 UVC 采集卡**：
   - M 系列 Max / Pro 跑 4K 或 2K：选支持 **NV12 无压缩** 的 USB 3.0（5Gbps）或 USB 3.2（10Gbps）HDMI 采集卡。
   - MacBook Air / 入门款跑 1080p：普通 USB 3.0 1080p60 免驱采集卡即可。

## 下载安装版快速上手（`.dmg`）

1. 打开 `Maccap-v1.0.0-macOS-arm64.dmg`，将 **Maccap.app** 拖入 **Applications（应用程序）**。
2. 首次打开若系统提示未验证开发者：在「应用程序」里**按住 Control（或鼠标右键）点 Maccap.app → 选「打开」**（或在「系统设置 → 隐私与安全性」底部点「仍要打开」）。
3. 首次运行允许「摄像头」和「麦克风」权限。
4. **不确定自己电脑带得动哪一档？** 打开软件后在画面任意位置**点鼠标右键**（或直接按 **`B` 键**），点菜单第一项 **「⚡ 一键测算本机接 PS5 推荐档位」**——程序会花约 3 秒实测你这台 Mac 跑 4K / 2K / 1080p 的真实毫秒数，直接弹窗给出最稳档位并支持一键应用。

## 4K / 2K / 1080p 算力换算与苹果电脑机型适配表

**30→60 帧不掉帧红线**：PS5 的 30 帧画面每 `33.3 毫秒` 来一张，扣掉送屏余量，**单张显卡补帧耗时必须 `≤ 25.5 毫秒`** 才能稳跑 60 帧不掉帧。

### 1. 分辨率换算底数（Apple M5 Max 40 核显卡·实测）

| 采集分辨率 | 像素量（相对 4K） | `[4]` 显卡·延迟低 | `[6]` 显卡·均衡 4.5 档 | `[5]` 显卡·画质好 | 实测算力比例 |
|---|---|---|---|---|---|
| **4K**（3840×2160） | 100% | **6.0 毫秒** | **11.1 毫秒** | **23.3 毫秒** | 基准 `1.0×` |
| **2K**（2560×1440） | 44.4% | **2.9 毫秒** | **4.2 毫秒** | **10.3 毫秒** | 耗时降为约 **`1 / 2.3`** |
| **1080p**（1920×1080） | 25.0% | **2.2 毫秒** | **2.6 毫秒** | **5.2 毫秒** | 耗时降为约 **`1 / 4.3`** |

### 2. M1–M5 苹果电脑接 PS5 选档参考表

> 说明：除 M5 Max（40 核显卡）为实机测量外，其余机型均按显卡核心规模与半精度算力比例换算，**标「推算未核实」**；装好软件后按 **`B` 键**即可测出你手头机器的真实毫秒数。

| 苹果电脑机型 | 显卡规模 | 接 PS5 推荐设置（右键菜单直接选） | 单帧耗时参考 |
|---|---|---|---|
| **M4 Max / M5 Max / 各代 Ultra**<br>（MacBook Pro / Mac Studio，32–80 核显卡） | 顶级 | **4K 原生 ＋ `[5]` 显卡·画质好**（追求更低延迟选 `[6]` 4.5 档） | M5 Max **实测 23.3 ms / 11.1 ms**；M4 Max 推算未核实约 25–27 ms / 13 ms |
| **M1 Max / M2 Max / M3 Max**<br>（MacBook Pro / Mac Studio，24–40 核显卡） | 高配 | **4K 原生 ＋ `[6]` 均衡 4.5 档**（M1 Max 重场景可切 `4K [4]` 或 `2K [5]`） | 推算未核实：4K 4.5 档约 15–25 ms；2K 5 档约 14–23 ms |
| **M4 Pro / M5 Pro**<br>（Mac mini / MacBook Pro，16–20 核显卡） | 中高配 | **4K 原生 ＋ `[4]` 延迟低**，或 **限制 2K ＋ `[6]` 4.5 档 / `[5]` 画质好** | 推算未核实：4K 4 档约 13–15 ms；2K 4.5 档约 9–11 ms |
| **M1 Pro / M2 Pro / M3 Pro**<br>（14/16 寸 MacBook Pro / Mac mini，14–19 核显卡） | 中配 | **限制 2K ＋ `[6]` 均衡 4.5 档**（4K 仅 `[4]` 档贴边可跑） | 推算未核实：2K 4.5 档约 12–17 ms；4K 4 档约 18–24 ms |
| **M3 / M4 / M5 基础版（带风扇）**<br>（Mac mini / iMac / 单风扇 14 寸 MBP，8–10 核显卡） | 入门带风扇 | **限制 2K ＋ `[4]` 延迟低**，或 **限制 1080p ＋ `[6]` 4.5 档** | 推算未核实：2K 4 档约 14–19 ms；1080p 4.5 档约 12–16 ms |
| **M1 / M2 基础版 & 全系 MacBook Air（无风扇）**<br>（M1–M4 Air / M1–M2 mini，7–10 核显卡） | 入门 / 无风扇 | **限制 1080p ＋ `[6]` 4.5 档 / `[4]` 延迟低**（防无风扇长时间发热降频） | 推算未核实：1080p 4.5 档约 15–23 ms；1080p 4 档约 12–19 ms |

## 鼠标菜单与快捷键

| 按键 / 操作 | 功能 |
|---|---|
| **卡片菜单 / `P`** | **没有画面时自动显示；播放中按 `P` 打开或收起。`←` `→` 选卡片，`↑` `↓` 选值，`Return` 确定，`Esc` 回到游戏。鼠标也能点卡片和选项** |
| **`F` / `⌘F` / 双击画面** | **在「标准桌面窗口模式」与「无边框全屏游玩」之间切换（全屏下按 `Esc` 退回窗口）** |
| **鼠标右键 / `M`** | 呼出快捷右键菜单 |
| **`B`** | **一键实测本机 4K / 2K / 1080p 补帧算力并推荐最佳档位** |
| **`1`** | 直通模式（不补帧，玩 PS5 原生 60 帧游戏时切这档，零等待延迟） |
| **`4`** | 显卡补帧·延迟低（1/4 光流估算） |
| **`6`** | 显卡补帧·均衡 4.5 档（默认，1/3 光流估算 + 4K 双三次重采样） |
| **`5`** | 显卡补帧·画质好（1/2 光流估算，适合 Max 芯片配 4K / 5K 屏） |
| **`2` / `3`** | 系统内置单块 / 分块补帧（需 macOS 26+） |
| **`K`** | 切换 5K 自适应锐化强度（关 `0.0` / 标准 `0.55` / 强 `0.90`） |
| **`U`** | 切换系统采集与 USB 256KB 无损直读（10G 采集卡可在右键菜单一键安装组件） |
| **`H`** | 状态条常显开关（实时查看帧率、等待毫秒数与丢帧数） |
| **`S`** | 保存最近 1 秒原始画面样本 |
| **`Q` / `Esc` / `⌘Q`** | 退出应用 |

## 从源码编译与打包 `.dmg`

需要安装 Xcode 命令行工具与 Metal 工具链（`xcodebuild -downloadComponent MetalToolchain`）：

```sh
./build.sh                  # 本地构建 Maccap.app
./tools/package_dmg.sh      # 净室构建 + 独立自检 + 隐私阻断扫描 + 生成可分发 .dmg
```

## 已知限制

- 专为 30 帧模式游戏补到 60 帧设计；原生 60 帧游戏请按 `1` 切直通。
- 快速大幅转动镜头时人物边缘偶有轻微半透明轮廓，属双帧光流估算固有边界。
- 游玩时建议关闭后台占满显卡的本地大模型或渲染任务，避免抢占 GPU 导致单帧超时。
